# CLI report example

`cli_test_report.json` is preserved byte-for-byte from the supplied
`cli_test_report.zip`. It is historical reference output, not a current scan.
Absolute source paths belong to the machine where it was generated, and current
rules may yield different finding counts.

Run `python cli_demo.py --repo sample_vulnerable_app --json scan-report.json` from
the repository root for a fresh report. See [CLI usage](../CLI_USAGE.md).
